# nasa_space_quiz

## Project Idea
NASA Space Quiz is a simple quiz that tests people on their knowledge of planets, NASA missions, and space exploration.

## How It Helps NASA
NASA wants to inspire students to learn about space and science (STEM). This quiz makes learning about space fun and interactive, and helps students remember important facts about our solar system and NASA's missions.

## Technologies / Tools Used
- GitHub (repository, issues, project board, branches, pull requests)
- Markdown (for writing the quiz and documentation)

## How to Use the Project
1. Open this repository on GitHub.
2. Go to the `quiz` folder.
3. Open a quiz file (for example `planets.md`) and read the questions.
4. Write down your answers on paper.
5. Open `answers.md` to check your answers and count your score.
